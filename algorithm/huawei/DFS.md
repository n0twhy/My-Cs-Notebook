[text](DFS/地铁耗时最短的线路.cpp)
两种解法：
DFS：递归枚举所有路径，维护 best_cost 和 best_path，到终点时比较更新，回溯时撤销 visited 和 path
Dijkstra：优先队列贪心，每次取当前最近未访问节点扩展，松弛时记录 prev，最后从终点反向回溯路径
关键点：Dijkstra 需要额外 prev 数组记录路径；建图阶段不能污染 visited/mark。

[text](DFS/最佳检测顺序.cpp)
题意：给一个森林（多棵树），每个节点挂了会影响所有下游子节点，按影响大小降序输出，相同则编号升序。
做法：建树（父→子方向），对每个根节点 DFS 算子树大小，子树大小减1就是影响数，排序输出。
关键点：每个节点最多依赖一个节点 → 森林结构；f[i] == -1 的是根节点，可能有多个根，都要 DFS；影响大小 = subtree_size - 1（不含自身）。
