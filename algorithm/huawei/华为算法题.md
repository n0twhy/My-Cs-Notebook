# 并查集
模板：
```
vector<int> parent;

void init() {
  for (int i = 0; i < parent.size(); ++i) {
    parent[i] = i;
  }
}

int find(int x) {
  return parent[x] == x ? x : parent[x] = find(x);
}

void unit(int x, int y) {
  parent[find(x)] = find(y);
}
```

并查集主要用于解决集合的合并与查询，常用于判断元素是否属于同一集合、连通分量。

# 树状数组

解决的是前缀和的更新，可以变成logn的复杂度

模板：
```
vector<int> tree;

int lowbit(int x) {
  return x & -x;
}

void update(int x, int add) {
  while (x < tree.size()) {
    tree[x] += add;
    x += lowbit(x);
  }
}

int query(int x) {
  int sum = 0;
  while (x > 0) {
    sum += tree[x];
    x -= lowbit(x);
  }
  return sum;
}
```
