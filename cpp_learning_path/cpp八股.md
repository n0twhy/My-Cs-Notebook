## 指针 & 引用
指针本身的大小是8字节

空指针：指针指向一个内存空间，内存空间被释放，就会成为悬空指针
野指针：不知道指向哪里的指针就是野指针

指针原本在内存中是占有空间的，而引用不会占空间，相当于变量的别名

### 常量指针 指针常量
const int *a：a指向的对象不能被修改
int const *b：b本身不能被修改

## 内存分区：全局、静态、栈、堆
高地址
+---------------------------+
|          stack            |  ← 局部变量、函数栈帧（一般向低地址增长）
|            ·              |
|            ·              |
+---------------------------+
|          (空洞)            |
|            ·              |
+---------------------------+
|          heap             |  ← new/malloc（一般向高地址增长）
+---------------------------+
|   .bss（未初始化全局/静态）  |
+---------------------------+
|   .data（已初始化全局/静态） |
+---------------------------+
|   .text（机器码，常数区等）  |
+---------------------------+
低地址

int g = 1; //.data 已初始化全局变量
int g2; //.bss 未初始化全局变量
static int s = 2; //.data 静态存储

void foo() {
  static int c = 3; // .data
  int x = 4; //stack
  int *p = new int(5); // p在stack，*p在heap
  delete p;
}

### static vs 全局变量
- static全局变量只能在本文件内被访问，作用域是文件内部
而普通全局变量，可以通过extern访问，作用域是整个程序
- static在类中声明的成员属于类本身而不是对象，被所有对象共享，且不可通过实例直接访问

### sizeof()
- 返回类型或变量所占字节数
- C中对空结构体sizeof(struct {})结果是0，cpp中空类是1，保证每个对象都有唯一地址

# 对象  继承  多态
## 构造 析构
构造函数：创建对象时自动调用
析构函数：对象声明周期结束时自动调用

### 为什么一般将 **析构函数设为虚函数**
当用基类对象的指针删除派生类对象时，如果不设为虚函数，他会只调用基类对象的析构函数
### **构造函数为什么通常不会做成一个虚函数？**
构造派生类时，基类部分要先构造，如果构造函数要是虚函数，会矛盾
### 虚函数  继承  多态
- 继承： 一个类有基类和派生类，派生类可以继承基类的public成员，进行重载或者重写
- 带虚函数的类编译器会为这个对象生成一张虚函数表，这是一张函数指针数组，每个指针指向一个当前类型该虚函数的最终实现，同时还会有一个指向虚函数表的虚指针
### 重载  重写
同名函数，不同传参就是重载
override就是，同名函数，同样的传参，重写

# 类
## 空类
- 空类的sizeof()一样是1，因为每个类对象都必须是唯一，也就是在内存上有单独的一个空间，如果为0就违背了这一原则。
- 只含虚函数的类通常只有8字节，because of vptr。虚函数表在全局静态区，唯一

## 左值  右值
- 左值：内存空间确定，有名字，能被多次赋值 
- 右值：临时对象，生命周期极短

### 移动语义
内存不动，所有权交换
### 深拷贝 浅拷贝
- 深拷贝：复制一份，再赋值
- 浅拷贝：类似于两个指针指向同一片内存

## 如何判断类相同
需要写一个运算符重载判断类相同
不能用memcmp比较，因为类存在内存对齐，会有一些闲置空间是系统随机padding的，其具体内容每个类都不一样

# 容器 迭代器
## push_back emplace_back
push_back是复制一份副本，将副本放在容器后
emplace_back是直接在容器后构造，避免一次拷贝

## map unordered_map
- map: 底层一般是红黑树结构
- unordered_map:是哈希表

## 容器的插入/删除
- vector/string 插入可能导致所有迭代器失效，删除中间元素的话会使后面的迭代器失效
- erase(it)会返回下一个迭代器

## priority_queue
优先队列，其底层数据结构是堆，可以定义大顶堆或者小顶堆，可以定义lambda，true则是第一个传参放在堆后面，所以greater就是小顶堆，less是大顶堆

## sort
主体是快排，递归过深时采用堆排，小范围数据用插入排序
平均是O(nlogn)，最坏情况有堆来兜底

# 智能指针
需要RALL语义防止内存泄漏的时候，就是智能指针发挥作用的场景，会在声明周期结束时自动释放，而不需要像普通指针需要delete
还有需要共享所有权，生命周期由多方决定
- shared_ptr是可共享的，内部有引用计数。引用次数归0时自动释放
- weak_ptr不会增加引用计数，不会影响对象声明周期
- unique_ptr是私有的智能指针，可以通过右值引用，然后move来转移

# 虚拟内存  进程内存
虚拟内存：是程序员看到的地址，他是逻辑上的地址，并不直接对应物理地址
物理内存：内存条上的地址
通过页表的mapping来映射，将虚拟内存地址瞬间翻译为真实物理地址上的数据

## malloc 
小内存 128kb，用brk，直接堆指针上移，但是可能存在内存碎片，比如申请 A，B，C，释放了B，中间空出来一块，但是堆顶指针不可能下移，这片内存就空出来了，不能还给os
大内存 用mmap，直接在栈和堆中间那片动态规划的区域划分一大片内存。释放立马就能还给os
