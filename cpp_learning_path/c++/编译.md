#ifndef MATH_H

`math.cpp`
```
#include "math.h"

int add(int a, int b) {
    return a + b;
}
```

预处理期已经很简单了，展开头文件，处理注释，然后处理宏定义

- 编译期
`math.s`
```
_Z3addii
```

`main.s`
```
call	_Z3addii@PLT
call	printf@PLT
```

`nm main.o` 查看符号表
```
                 U _Z3addii  未定义
0000000000000000 T main      已经定义，在text文件中相对偏移是0
                 U printf    未定义
```
`objdump -r main.o`查看重定向表
```
OFFSET           TYPE              VALUE
0000000000000017 R_X86_64_PLT32    _Z3addii-0x0000000000000004
0000000000000026 R_X86_64_PC32     .rodata-0x0000000000000004
0000000000000033 R_X86_64_PLT32    printf-0x0000000000000004
```

- 链接期
`_Z3addii` 的处理
1. linker会在所有传入的.o文件中查符号表
2. 查到`_Z3addii`是T，已经定义
3. 直接链接进可执行文件，得到最终地址

`printf` 的处理
1. linker会在所有传入的.o文件中查符号表 -> 找不到
2. 去静态库.a或者动态库.so里找
3. 在libc.so里找到printf
4. 这是动态库的符号，走PLT
5. 可执行文件里生成PLT跳板的地址，而不是printf的真实地址
6. 最终 main 里的 `call` 变成 `call printf@plt`,经过跳板

```
call   1187 <_Z3addii>
call   1050 <printf@plt>
```
