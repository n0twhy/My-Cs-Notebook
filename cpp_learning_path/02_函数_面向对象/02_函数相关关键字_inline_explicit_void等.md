## 函数相关关键字：inline / explicit / void 等

可以在这里整理和实现这些问题：

- **什么是内联函数（inline）？宏定义与内联函数的区别？**
- **include "" 和 <> 的区别是什么？**
- **void* 是什么？可以做哪些操作？**
- `malloc` 的参数、返回值、`void*` 怎么转化为其它类型？
- `sizeof` 和 `strlen` 的区别是什么？`sizeof(1==1)` 在 C 和 C++ 中分别是什么结果？
- `explicit` 的作用是什么？防止哪些隐式转换？
- `memcpy` 函数的底层原理 / 实现思路？
- `strcpy` 函数有什么陷阱？

建议：分别用宏函数、inline 函数实现简单功能，比对可读性和调试体验；写几个需要/不需要 explicit 的构造函数来体会。
