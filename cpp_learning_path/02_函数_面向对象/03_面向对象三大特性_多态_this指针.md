## 面向对象三大特性、多态与 this 指针

可以在这里整理和实现这些问题：

- 什么是 **面向对象**？面向对象的三大特性（封装、继承、多态）？
- 如何理解 C++ 是面向对象编程语言？
- **重载、重写（覆盖）、隐藏** 的区别？
- `this` 指针的含义？在成员函数、静态成员函数中的区别？
- C++ 中的 **多态** 是什么？如何通过虚函数实现运行时多态？
- C++ 中多态的具体实现机制（虚函数表、虚指针的大致思想）？

建议：写一个基类 + 多个派生类，通过基类指针/引用调用虚函数，对照虚函数与非虚函数的行为差异。

1.面向对象就是cpp的函数功能实现可以封装在类中，外部调用者可以通过类的接口进行访问
2.继承就是他有基类，还有子类可以继承基类的特征和行为，子类有基类的非private变量和函数，还可以进行重写
3.多态就是不同继承类的对象，会对同一消息做出不同的相应

4.重载就是在同一个类中，存在同名函数，该函数传参的类型和数量不同，就会发生重载，会根据函数传参类型和数量自动分配
隐藏就是子类的同名函数会将基类的同名函数进行隐藏，如果要使用的话可以指明::
重写就是override，派生的子类重写的函数必须与基类的返回类型，传参完全一样
5.运行时多态就是03cpp中的实现
6.每一个class类都有其专门的虚函数表，当调用其对象时会自动取虚函数表里的方法
