## static vs 全局变量

# C++编译
- 预处理：对源码进行处理，展开宏定义，比如#include, #define #ifdef等
- 编译：将源代码翻译为汇编语言，生成汇编代码
- 汇编：将汇编代码转换为可执行的目标文件
- 链接：将目标文件与其他必要的库文件链接在一起，生成可执行的程序
## 静态链接 动态链接
- 链接方式：静态链接是直接将库复制到可执行文件中，而动态链接则是引用，在运行时由操作系统动态加载
- 文件大小：静态使可执行文件的大小增加，动态因为是引用，则不会
- 内存占用：库在执行时会完整加载到内存中，占用固定的内存空间，动态链接库只有被运行时才会被加载
- 可扩展性：动态更好，可以在不修改可执行文件的情况下添加新的库文件。

### 移动语义
#### 左值 vs 右值 (& vs &&)：
左值 (&)：内存确定，有名字，还会继续存活。代表借用，绝不能掏空其内部资源。
- 右值 (&&)：临时对象，马上消亡。代表接管/废品回收，可以肆无忌惮地夺走其指针并将其置空。
- std::move：本质：只是一个无开销的强制类型转换，将左值强行转换为右值引用 (&&)。
注意：它本身绝对不移动任何数据，也不置空指针。它只是给编译器发通行证，引导代码去调用带有 && 参数的移动函数。
#### 移动构造 vs 移动赋值：
= 移动构造 (Type(Type&&))：对象刚刚诞生时调用。手里没旧东西，直接偷（抢走指针，对方置为 nullptr）。
- 移动赋值 (operator=(Type&&))：已经存在的对象换新值时调用。必须先释放自己原本持有的资源（如 Unpin），再去偷，否则会导致内存/资源泄漏。
- Swap 惯用法：移动赋值的最佳写法是用 std::swap，将旧资源直接塞给右值，让它在析构时顺手替你释放（借刀杀人）。构造与赋值的判别法则（看 = 号左边）：有类型名（如 Type a = b;）：伴随声明的初始化 $\rightarrow$ 调用构造函数（拷贝/移动）。无类型名（如 a = b;）：老对象换值 $\rightarrow$ 调用赋值运算符（拷贝/移动）。
#### noexcept
移动构造和移动赋值必须加上 noexcept 关键字。若不加，在如 std::vector 扩容搬运对象时，标准库为防抛出异常导致状态损坏，会拒绝移动，强制退化为拷贝，极易引发浅拷贝导致的 Double Free/Unpin。

#### 万能引用
`T&&` 这个既能接受右值也能接受左值

#### 引用折叠
当使用万能引用的时候，如果传进来的本身又是一个引用
& + & = &
& + && = &
&& + & = &
&& + && = &&

#### 完美转发
一个右值一旦有了名字，那他就变成了左值
函数内部传参的时候，这个传进来的右值其实是有名字的，这个变量在这个函数体里面就是左值，如果这时候把这个变量传给下一个函数，他就不再是右值了，引发不必要的拷贝
std::forward会保留原来的属性

### "shared_ptr 是怎么实现的？内部结构？" 
每个智能指针内部都有两个指针，一个指向对象，一个指向一个数据结构，里边装了强引用计数和弱引用计数，shared是增加强的，拷贝一次+1,声明周期结束-1，如果强引用为0了，自动释放，调用对象的析构函数
### "shared_ptr 线程安全吗？" （最容易答错）
内部一个指针指向对象，一个指针指向控制块，块里的引用计数是原子性的(引申一下，atomic保证的是CPU指令级的原子性，CAS，原理类似于自旋锁)
但是shared_ptr本身并不线程安全，比如一个场景一个线程拿到了他，立马切出去线程B也拿到他了，并且指向的对象变成nullptr，原线程的就是悬空指针了
### "weak_ptr 解决什么问题？lock() 怎么实现？" 
可以解决shared_ptr循环引用的问题，比如对象A持有对象B的智能指针，对象B持有对象A的智能指针，两个引用计数永远不会自动析构归0。内存泄漏
### "make_shared 和 new T + shared_ptr 有什么区别？" 
makeshared直接malloc一大片内存用于装构造的对象和对应控制块
new shared malloc两次，第一次是为构造对象，第二次是为控制块

## malloc 
小内存 128kb，用brk，直接堆指针上移，但是可能存在内存碎片，比如申请 A，B，C，释放了B，中间空出来一块，但是堆顶指针不可能下移，这片内存就空出来了，不能还给os
大内存 用mmap，直接在栈和堆中间那片动态规划的区域划分一大片内存。释放立马就能还给os
### malloc vs new
new会调用构造函数，malloc不会，永远只给一块未初始化的字节。
new->delete, malloc->free
new是类型安全的，malloc返回void* 指针

## CAS
bool CAS(T* addr, T expected, new_value) {
  if (*addr = expected) {
    *addr = new_value;
    return true;
  }
  return false;
}

### 盲区
